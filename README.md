A program that writes one funny one-line software patch note for a bug in
real life to `/output/entry.txt` — an entry for
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d)
on make.fun. A house judge compares the lines pairwise: a real release-note
register, a specific recognisable bug of the body, and a joke that lands on
first read.

## The line

> v2.4.1: fixed a bug where the brain replayed your most embarrassing moment from 2009 every time you tried to fall asleep.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (121 characters, within the 1–160 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-line patch note to `entry.txt`.
